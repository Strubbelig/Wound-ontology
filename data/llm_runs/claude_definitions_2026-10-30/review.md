## Not written

* **Aseptic cuticle plan specification** (< treatment plan specification): cannot: The label 'Aseptic cuticle' is unclear and appears to be a mistranslation of German 'aseptische Kautelen' (aseptic precautions), which would duplicate row 16, so the label needs correction first.
* **Bepanthen ointment** (< Wound gel/ointment/cream): cannot: The class is named by a proprietary brand product, so a definition would have to use the brand name or would instead define a generic dexpanthenol ointment; the class should be relabelled or replaced by a generic class.
* **Bismuth III bromide** (< Material used for wound treatment): cannot: Inorganic bismuth(III) bromide is not an established wound antiseptic, and the label probably conflates it with bismuth tribromophenate, so the intended substance is unclear.
* **Hand disinfection plan specification** (< Aseptic cuticle plan specification): cannot: The parent label 'Aseptic cuticle plan specification' is unclear and probably a mistranslation of 'aseptische Kautelen' (aseptic precautions), so the required genus would be misleading until the parent is corrected.
* **Immunosuppression** (< material disease entity): cannot: Immunosuppression names a reduced capacity of the immune system or the act of suppressing it (a disposition, state or process, often intended therapy), not a material entity classified as pathological, so the parent does not fit.
* **Planimetry** (< Wound size measurement process): cannot: Planimetry measures wound surface area, but the parent is defined as having a wound depth measurement datum as output, so any genus-differentia definition would assert something false; the parent definition must first be corrected to cover wound size in general.
* **Redness** (< color): cannot: 'Redness' cannot be distinguished from its sibling 'reddened', which already names the reddened colour of a bearer, so the classes appear to be duplicates and should be merged or clarified.
* **Surface disinfection plan specification** (< Aseptic cuticle plan specification): cannot: The parent label 'Aseptic cuticle plan specification' is unclear and apparently concerns skin, whereas surface disinfection usually refers to inanimate surfaces, so the parent does not demonstrably fit the label.
* **Thread size 1-0** (< Thread size): cannot: In USP notation 1-0 is an alternative writing of size 0, so this class appears to duplicate 'Thread size 0' and no distinct differentia can be written.
* **URGE scale** (< Wound classification scale): cannot: No established wound classification scale named URGE is known, and nothing is given that says what it classifies or how.
* **Voltaren gel** (< Wound gel/ointment/cream): cannot: The label is a brand name of a topical diclofenac preparation for application to intact skin, which does not fit the parent wound gel/ointment/cream, and brand names are excluded.
* **Wagner and Anderson wound classification** (< Wound classification scale): cannot: It is unclear which scale 'Wagner and Anderson' denotes (it is not a recognized name of the Meggitt-Wagner or another established wound scale), so its content cannot be stated without guessing.
* **Wound fabric adhesive plan specification** (< Wound closure technique plan specification): cannot: The label 'fabric adhesive' is ambiguous: it could mean a tissue adhesive (a likely mistranslation of German 'Gewebekleber') or fabric adhesive closure strips, so the technique specified cannot be determined without guessing.
* **Wound pocket** (< material entity): cannot: A wound pocket is a cavity, i.e. a space (a BFO site or immaterial entity) extending beneath intact tissue, so the parent 'material entity' does not fit what the label names.
* **Wound staple plastering plan specification** (< Wound closure technique plan specification): cannot: The label is unclear: 'staple plastering' may mean skin closure with staples or closure with adhesive strips (a literal rendering of German 'Klammerpflaster'), and these are different techniques.
* **Wound-integrating wound dressing** (< Wound dressing): cannot: 'Wound-integrating' is not an established wound care term; it might mean resorbable dressings incorporated into new tissue or something else, so any definition would be a guess.
* **Wounds classified according to Tscherne and Oestern** (< Wound with accompanying fracture): cannot: The Tscherne and Oestern system also grades soft tissue injuries of closed fractures, where the skin may be intact, so the parent 'Skin wound' does not fit everything the label covers.
* **wound signaling function** (< function): cannot: The label is ambiguous: it could mean a dressing that indicates wound status or biological signalling in wound healing, and nothing in the row settles which.
* **first wound dressing layer function** (< wound dressing layer function): cannot: The row does not say what makes a layer 'first', such as whether layers are counted from the wound side, so no sound differentia can be given.
* **second wound dressing layer function** (< wound dressing layer function): cannot: The row does not say what makes a layer 'second' or how layers are ordered, so no sound differentia can be given.
* **wound infecting tendency** (< tendency): cannot: The label is ambiguous between a wound's tendency to become infected and an agent's tendency to infect wounds, and the row does not settle which.
