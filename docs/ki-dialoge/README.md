# KI-Dialoge zur Masterarbeit „Eine umfassende Ontologie der Wunde“

Dieser Ordner enthält die Dialoge mit Claude Code (Anthropic, Modell Claude Opus 5.5), die bei der Entwicklung von MILD und WONT und beim Schreiben der Masterarbeit geführt wurden. Die Arbeit verweist auf sie als Anhang A-1 bis A-12 (Tabelle „Dialoge mit Claude Code“).

*AI dialogues (Claude Code) behind the master's thesis on MILD and WONT, cited there as appendix A-1 to A-12.*

## Inhalt

- `A-1_….html` bis `A-12_….html`: je ein Dialog mit Zeitstempeln. Nachrichten des Autors und Antworten von Claude stehen vollständig darin. Werkzeugaufrufe erscheinen als einzeilige Beschreibung, ihre Ausgaben sind nicht enthalten. Nachrichten anderer Claude-Sitzungen und Systemmeldungen sind als „nicht vom Autor“ gekennzeichnet. E-Mail-Adressen Dritter und Zugangsschlüssel sind maskiert.
- `index.html`, `index.json`: Übersicht über alle Dialoge.
- `KI-Dialoge_2026-11-01.zip`: alle Dateien in einem Archiv.

GitHub zeigt HTML-Dateien als Quelltext an. Zum Lesen die ZIP-Datei herunterladen und `index.html` im Browser öffnen.
