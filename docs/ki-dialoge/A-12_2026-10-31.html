`★ Insight ─────────────────────────────────────`
- The test asserts disorders only as "material entity that has a `pathological` quality" and lets the reasoner infer `material disease entity` through the equivalence axiom. Removing that equivalence in a scratch copy made four questions fail, so the passes depend on real reasoning, not on asserted types.
- Probe classes (intersections such as `disease diagnostic result and material disease entity`) run in a second ROBOT pass, because ROBOT writes no output when a class is unsatisfiable. Five probes are unsatisfiable as required.
- ELK is an OWL 2 EL reasoner: it ignores inverses and `differentFrom` and never derives `sameAs`. The "do not collapse" checks are therefore structural under ELK (no functional or inverse-functional property, no cardinality cap, no `sameAs` in the output). The test asserts `owl:differentFrom` for every pair that must stay distinct, so a HermiT run would turn a forced identity into an inconsistency.
